# 3D Rasterization

## Setup and build

Requires Python 3 and a C++20
From repo root, run:

`make`

This will set up the Python venv and compile everything. After `make` finishes, run `source .venv/bin/activate` and `python -m rasty` to run the whole thing.

GUI:
- chooses obj file path and select renderer. Then **open scene** will render
The scene is currently an empty, waiting  for the future renderer; **Back** returns to settings.
